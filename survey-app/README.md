# 척도 응답 수집 앱 (Google Apps Script)

휴대폰(안드로이드) 브라우저에서 쓰는 설문 앱과, 결과를 한눈에 보는 관리자 화면이에요.
홈페이지(casenote)와는 따로 동작해요.

- **문항 내용과 응답은 이 저장소에 없어요.** 모두 내 Google 스프레드시트에만 저장돼요(저장소가 공개라서).
- 처음에는 응답이 0개예요. 기존 엑셀(504명) 응답은 넣지 않고 **새 피험자 응답만** 쌓여요.

## 파일

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버: 문항 읽기, 응답 저장, 총점 계산, 관리자 로그인 |
| `index.html` | 참여자 화면: 동의 → 기본 정보 → 척도별 문항 → 제출 |
| `admin.html` | 관리자 화면: 한눈에 보기, 척도 점수 · 신뢰도(α), 참여자별 결과, CSV 내려받기(이름 제외) |
| `style.html` | 두 화면이 같이 쓰는 차분한 어두운 색 디자인 |

## 스프레드시트 시트

| 시트 | 내용 |
|---|---|
| 설정 | 관리자 비밀번호, 연구 제목 · 설명, 동의 문구, 연락처, 마무리 안내 |
| 척도 | 순서, 응답 범위, 응답 보기(`|`로 구분), 안내문, 조건(`relation` 연인 경험자만 · `breakup` 이별 경험자만 · `work` 직장 경험자만), 사용(Y/N) |
| 문항 | 척도코드, 문항번호, 하위요인, 역채점(Y), 문항 내용 |
| 점수 | 계산할 점수(하위요인 · 총점)와 포함 문항 |
| 응답 · 참여자 | 첫 응답이 들어올 때 자동으로 생겨요. 이름은 `참여자` 시트에만 따로 저장돼요 |

## 설치 순서

1. `앱_문항설정.xlsx`를 Google Drive에 올리고, 더블클릭 → **Google 스프레드시트로 열기**(파일 › Google 스프레드시트로 저장).
2. `설정` 시트에 **관리자 비밀번호**를 적어요.
3. 메뉴 **확장 프로그램 › Apps Script**를 열어요.
4. 왼쪽 파일 목록에서 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여 넣어요.
5. **+ › HTML**로 `index`, `admin`, `style` 파일 3개를 만들고 각각 같은 이름 파일 내용을 붙여 넣어요.
6. 오른쪽 위 **배포 › 새 배포 › 웹 앱**: 실행 사용자 = **나**, 액세스 권한 = **모든 사용자**. 권한 허용.
7. 나온 주소(`…/exec`)가 참여자 주소예요. 관리자 화면은 주소 뒤에 `?page=admin`을 붙여요.
8. 안드로이드 Chrome에서 주소를 열고 **⋮ › 홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

코드를 고친 뒤에는 **배포 › 배포 관리 › 수정(연필) › 버전: 새 버전**으로 다시 배포해야 반영돼요.
